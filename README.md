# USA 2026: Senát — veřejný experiment s AI forecastingem

Pravděpodobnostní předpovědi voleb do Senátu USA 3. 11. 2026 (9 senátních závodů + kontrola Senátu a Sněmovny):
čistá AI bez kurzů a bez volebních modelů (*blind*), extremizovaná AI, sázkové kurzy (Tipsport, Fortuna), jejich kombinace
a profesionální volební model jako srovnání. Předpovědi tvoří AI pipeline (Claude) s člověkem ve smyčce.
Navazuje na [Senát ČR 2026](https://josefslerka.github.io/senat-2026-forecast/) a
[Slovensko 2026](https://josefslerka.github.io/sk-volby-2026-forecast/).
